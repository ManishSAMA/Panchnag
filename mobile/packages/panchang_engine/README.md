# panchang_engine

Pure-Dart port of the Jain Panchang engine for the mobile app. The Python
engine in `python_engine/` is the reference; `test/parity/` checks this
package against the fixtures it exports (`test/fixtures/core/`).

```bash
dart test
```

Design: `python_engine/python_engine/plans/mobile-phase2-dart-engine.md`.
